# Add repository discovery and scan-friendly state

Preserve the approved English graphite Library, compact Cards, larger type, rounded shapes and inset Assistant. No image-generation tool is available; use the verified incumbent and this scoped change list.

Add repository opens a GitHub search dialog. Its single search field accepts keywords, owner/repo or a GitHub URL. Search results show full repo name, About, language and star count. An explicit Add to Library action adds a Card without installing it; duplicates become In Library. Keep the dialog open for adding multiple repos. Existing results show their Library installation status.

State treatment: labelled pills with a readable border/background. Enabled is green, Disabled is amber, Not installed is neutral, and In Library is green with a check. Color supplements text. Apply the same state vocabulary in Cards, discovery and Assistant context.

Use public read-only GitHub API requests; no credentials in the client. Show loading, empty, unavailable/rate-limit and recovery states. Cancel stale searches on input edits, replacement requests or dismissal. Prototype additions remain in memory; unknown installation details are not fabricated.
